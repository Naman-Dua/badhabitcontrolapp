# Future Backlog — Not MVP

These ideas are intentionally deferred and must not creep into the MVP without a separate product decision.

## Possible Future Features

- Backup/export
- Optional encrypted backup
- Optional cloud sync
- More advanced trend charts
- More detailed reminder scheduling
- Optional biometric/app lock
- More habit types
- Custom trigger sets
- Advanced intervention exercises
- Wearable integration

## Rule

Future additions must preserve the core identity:

**calm + personal + private + useful + non-gamified**
