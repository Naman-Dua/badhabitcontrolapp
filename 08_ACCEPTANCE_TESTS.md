# Acceptance Tests

## Home

- Both default habits are visible.
- Their streaks are independent.
- Selecting one habit never changes the other habit's current streak.

## Calendar

- Previous months are browsable.
- Calendar states are understandable without color alone.
- A relapse day is shown distinctly.
- Historical days remain after a relapse.

## Urge Flow

- User can start an urge flow from either habit.
- Intensity can be selected.
- Timer duration can be selected from 3/5/10/15 minutes.
- Trigger can be selected without text entry.
- Timer remains correct through recomposition.
- Completing the timer allows an outcome to be stored.

## Relapse

- Recording a relapse resets only the chosen habit's current streak.
- Longest streak is preserved.
- Previous calendar records are preserved.
- The other habit remains unchanged.

## Persistence

- Data survives app restart.
- Core features work offline.
- Duplicate button taps do not create duplicate day records.

## Privacy

- No account is required for the MVP.
- Habit/urge history is stored locally.
- No habit content is uploaded by the MVP.
