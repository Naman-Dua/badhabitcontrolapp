# Master Project Context

## Product Name

Working title: **Bad Habit Control**

## Purpose

A calm Android app made personally for the user to manage two specific habits: cigarettes and masturbation.

## Locked Product Decisions

- Exactly two habit sections.
- Each habit has its own streak.
- Each habit has its own date-based calendar.
- Each habit has its own history and statistics.
- The home screen shows both habits.
- The current streak is visually large and prominent.
- The interface should feel calm.
- Urge intervention is a central feature.
- Urge timer choices: 3, 5, 10, 15 minutes.
- Urge-wave visualization during the timer.
- Quick trigger selection instead of journaling.
- Relapse resets only the selected habit's current streak.
- Historical progress is preserved.
- Local/offline MVP.

## Explicitly Excluded

- Motivational messages
- Motivational quotes
- Milestones
- Achievements
- Badges
- XP
- Levels
- Gamification
- Journaling
- Local/app lock
- Social/community features
- Leaderboards
- Mandatory login

## Product Tone

Calm, direct, non-judgmental, private, minimal.

Avoid language such as:

- "You failed"
- "Don't disappoint yourself"
- "You lost everything"
- "Be stronger"

Use neutral records such as:

- "Relapse recorded"
- "Current streak: 0 days"
- "Previous longest streak: 27 days"

## Primary User Loop

1. Open app.
2. See two large streaks.
3. Select the habit when needed.
4. Tap `I'm Having an Urge`.
5. Choose intensity.
6. Choose timer duration.
7. Wait through the calm urge-wave timer.
8. Record outcome.
9. View the event in history/calendar.
10. Continue tracking.
